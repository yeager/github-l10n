# GitHub L10n

Scan popular GitHub repositories for missing translations.

Built with GTK4/Adwaita. Part of the [Danne L10n Suite](https://github.com/yeager/debian-repo).

## Installation

### Debian/Ubuntu
```bash
sudo apt install github-l10n
```

### Fedora/RPM
```bash
sudo dnf install github-l10n
```
